# Claude Code PR Reviewer Sub-Agent

> Intelligent sub-agent that analyzes GitHub pull request diffs and posts structured Markdown review comments.
> Solves **[Bounty #4 ($150)](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/4)**.

---

## 🚀 CLI Usage

```bash
# Basic review (outputs to terminal)
python claude_review.py --pr https://github.com/owner/repo/pull/123

# Review and post directly as a PR comment
GITHUB_TOKEN=your_pat python claude_review.py --pr https://github.com/owner/repo/pull/123 --post-comment
```

---

## ⚙️ GitHub Action Setup

Add the included workflow (`.github/workflows/claude-review.yml`) to your repository. Every opened or updated Pull Request will automatically receive a structured code review comment from Claude.
