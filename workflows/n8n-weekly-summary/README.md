# 🚀 Automated Weekly GitHub Dev Summary with Claude & n8n

> A production-grade n8n workflow that automatically analyzes a GitHub repository's weekly activity (commits, closed issues, merged PRs) and generates an executive narrative summary using Claude (`claude-sonnet-4-20250514`), delivered directly to Discord, Slack, or Email.  
> **Solves [Bounty #5 ($200)](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5)**.

---

## 📋 Features

- ⏰ **Automated Trigger**: Runs every Friday at 5:00 PM (`0 17 * * 5`).
- 🐙 **GitHub Integration**: Automatically pulls commits, merged pull requests, and closed issues for the past 7 days.
- 🧠 **Claude Sonnet Intelligence**: Leverages `claude-sonnet-4-20250514` to synthesize technical activities into an inspiring, cohesive narrative.
- 🌐 **Multi-Language Support**: Configurable summary output in **English (`EN`)** or **French (`FR`)**.
- 📬 **Flexible Delivery**: Ready for Discord webhooks, Slack incoming webhooks, or email forwarding.

---

## ⚡ Setup Instructions (5 Steps)

1. **Import Workflow**: In your n8n workspace, navigate to **Workflows > Import from File** and select [`weekly_dev_summary_n8n.json`](./weekly_dev_summary_n8n.json).
2. **Set Claude Credentials**: In n8n credentials or environment variables, add your `ANTHROPIC_API_KEY`.
3. **Configure Settings**: Double click the **Config Variables** node and set:
   - `GITHUB_OWNER`: Your GitHub organization or username (e.g. `claude-builders-bounty`).
   - `GITHUB_REPO`: Target repository name.
   - `SUMMARY_LANGUAGE`: `EN` or `FR`.
   - `DESTINATION_WEBHOOK_URL`: Your Discord or Slack incoming webhook URL.
4. **Test Run**: Click **Execute Workflow** to test data fetching, Claude generation, and delivery.
5. **Activate**: Toggle the workflow switch to **Active** to enable automatic Friday 5:00 PM scheduling.

---

## ⚙️ Configuration Variables

| Variable | Type | Default | Description |
|---|---|---|---|
| `GITHUB_OWNER` | String | `claude-builders-bounty` | GitHub repository owner/org |
| `GITHUB_REPO` | String | `claude-builders-bounty` | GitHub repository name |
| `SUMMARY_LANGUAGE` | String | `EN` | Output language: `EN` (English) or `FR` (French) |
| `LOOKBACK_DAYS` | Number | `7` | Activity window in days |
| `DESTINATION_WEBHOOK_URL` | String | Discord / Slack Webhook URL | Destination channel webhook endpoint |
